# CANgauge-core
## About
CANgauge is an open source 60mm gauge designed for automotive applications. It offers 2x CAN ports, I2C, and Full Speed USB. This repo is meant to serve as a starting point for users who want to develop their own application on CANgauge. It includes and ports FreeRTOS and LVGL so you can skip the bring-up and go straight to application development.

If you're looking for the source code of the default OBDII app it can be found here: https://github.com/alex-jegers/CANgauge-OBDII.

## Getting Started
### Clone Repos
This section describes how to get started writing code in STM32CubeIDE. If you follow these steps all the include paths, build outputs, and compiler settings are already configured.
1. Start by cloning the STM32CubeIDE project settings
   * `git clone https://github.com/alex-jegers/CANgauge-STM32CubeIDE-project.git`
2. Change directories into the newly created folder.
    * `cd CANgauge-STM32CubeIDE-project`
3. Clone the CANgauge-core repo (this repo).
   * `git clone https://github.com/alex-jegers/CANgauge-core.git`
### Writing Code
In [main.c](main.c) a FreeRTOS task `void application_task(void* args)` is created before the scheduler starts in `int main(void)`. Your application code can start in application_task. The definition for application_task is at the bottom of main.c and is included here for reference:
```c
void application_task(void* args)
{
  /******************************************
  *** USER APPLICATION TASK INITIALIZATION
  *** CODE GOES HERE. THIS WILL RUN
  *** AT THIS TASKS PRIORITY (1).
  ******************************************/

  lv_demo_music();

  while (1)
  {
    /***************************************
    *** USER APPLICATION CODE GOES HERE ***
    ***************************************/

    const uint32_t delay_time_ms = 25;		//Some amount of delay time is recommended to let the FreeRTOS idle task (priority 0) run.
    vTaskDelay(pdMS_TO_TICKS(delay_time_ms));
    /*********************************
    *** END USER APPLICATION CODE ***
    *********************************/
  }
}
```
By default the LVGL music player demo is ran. This line can of course be removed and replaced with your application initialization code.
### Reprogramming the Gauge
#### ST-Link or debugger
It's not required but using a ST-Link is the recommended way to program and debug an application. There is a programming header, J3, on the CPU board (the PCA closest to the LCD). 
#### USB Bootloader
To program the gauge without a debugger, hold down the physical button on the back of the gauge while connecting it to the computer via USB. When the gauge powers up it will be in bootloader mode and will appear as a Mass Storage Device on your PC. Drag and drop the .bin file generated by STM32CubeIDE into the firmware folder. It will appear on the gauge. Select the file and press upload.
